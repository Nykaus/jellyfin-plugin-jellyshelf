Bibliothèque Calibre

Dossier contenant metadata.db. Laisser vide pour une détection automatique (le plugin remonte l'arborescence à partir de chaque livre). La base est ouverte en lecture seule ; aucun fichier n'est déplacé ni modifié.

Navigation — genres & tags

Libellé de la colonne personnalisée Calibre servant de genre / niveau 1 (ex. type pour #type : Romans, Mangas, BD…).
La vue « Genres » de la bibliothèque regroupera alors les livres par type (Romans, Mangas…).
Désactivé par défaut : si « type » alimente déjà le genre, activer ceci mélangerait les tags (Fantasy, manga, littérature…) dans les genres.

Collections (variables Calibre)

La tâche « JellyShelf — Construire les collections » (Tableau de bord → Tâches planifiées) crée une collection par valeur du champ indiqué. Tout se fait en données via l'API Jellyfin : aucun fichier ni raccourci n'est créé, Calibre n'est jamais modifié. Lancer une analyse de la bibliothèque d'abord (les livres doivent porter leur identifiant Calibre).
Ex. Type — | {#type} et Série — | {series} → une collection par type (Type — Romans, Type — Mangas…) et par série. Champs : title, author, series, publisher, year, rating, tag, et toute colonne perso #libellé. Chaque collection a sa propre page/URL dans Jellyfin.

Dossier miroir (bibliothèque livres dédiée)

Crée un dossier de raccourcis (liens symboliques) vers tes livres Calibre, rangés selon ton gabarit. Tu crées ensuite une bibliothèque Livres Jellyfin dédiée pointant sur ce dossier → une page à part, livres uniquement, jamais mélangée avec les films ni les collections. Calibre n'est jamais modifié. Lancer ensuite la tâche « JellyShelf — Générer le dossier miroir (liens) ».
Ex. /tri. Doit être séparé de la bibliothèque Calibre (jamais à l'intérieur) et monté en écriture dans le conteneur Docker.
Ex. Par type | par_type | {#type}/{series?}/{title}
Tokens : {champ}, {champ?} (sauté si vide), {champ*} (un dossier par valeur). Champs : title, author, series, seriesindex, publisher, year, rating, tag, et toute colonne perso #libellé (ex. #type, #editeur).
